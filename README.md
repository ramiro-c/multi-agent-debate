# multi-agent-debate

Sistema multi-agente donde varios proponen soluciones, un crítico
evalúa, hay votación/consenso y un agregador entrega el resultado
con nivel de confianza.

**Qué demuestra:** consenso entre agentes y reducción de sesgo individual.

## Checklist de features clave

- [ ] Múltiples agentes que proponen respuestas
- [ ] Crítico que evalúa propuestas
- [ ] Mecanismo de votación / consenso
- [ ] Agregador final con score de confianza
